# MAIA

*My Assistant In the Apartment* — hub per la casa che gira su mobile, PC e TV.
Prima sezione: **MAIA TV**, catalogo unico dei servizi di streaming gratuiti con player integrato.

```
maia/
├── maia-be/   # NestJS + Prisma (PostgreSQL)
└── maia-fe/   # Next.js + Tailwind + React Query
```

I tipi del frontend verranno generati dall'OpenAPI del backend (`@nestjs/swagger` + `openapi-typescript`).
